Wanderlust

Airbnb-style property listing & booking platform

Node.jsExpress.jsMongoDBEJSCloudinaryLeaflet.jsPassport.js
Live Demo GitHub

Problem Statement

Travelers need a platform to discover and list unique stays. Wanderlust solves this with a full-featured Airbnb-inspired web app — complete with auth, maps, and cloud image hosting.

What I Built

  • Full user authentication & authorization with Passport.js (local strategy)
  • CRUD operations for property listings with ownership checks
  • Cloud image uploads via Cloudinary with URL generation
  • Interactive property location maps using Leaflet.js with OpenStreetMap tiles
  • User review and star rating system
  • Flash messages, error middleware, and input validation
  • MVC architecture with clean route separation
  • Fully responsive — works on all screen sizes

Engineering Decisions

  • Used Mongoose for schema design with validation at the model level
  • Implemented middleware-based authorization (only owners can edit/delete)
  • Multer + Cloudinary integration for seamless image upload and URL generation
  • Session-based auth with connect-mongo for persistent sessions

Planned Improvements

  • 📅 Calendar-based booking with availability blocking
  • 💬 Real-time host-guest messaging via Socket.io
  • 💳 Payment integration with Razorpay
  • 🔍 Advanced search & filters (price range, location radius)
  • 📊 Host analytics dashboard

RBAC System

Role-Based Access Control with JWT authentication

Node.jsExpress.jsMongoDBJWTbcryptREST API
Live API GitHub

Problem Statement

Most beginner APIs skip proper access control entirely. This project implements production-standard RBAC — where different users (Admin, Manager, User) have distinct, enforced permissions across all routes.

What I Built

  • Three-tier role system: Admin, Manager, and User with distinct access levels
  • JWT-based stateless authentication with token expiry
  • Password hashing with bcrypt (salt rounds configurable)
  • Role-checking middleware applied per route
  • User registration, login, logout, and profile APIs
  • Admin-only routes for user management and role assignment
  • RESTful API design with proper HTTP status codes and error messages
  • Input validation and centralized error handling

Engineering Decisions

  • Chose JWT for stateless auth — scalable for microservices
  • Role stored in JWT payload to avoid extra DB calls per request
  • Middleware chain: authenticate → authorize(role) → handler
  • Separate routers for auth, user, and admin operations

Planned Improvements

  • 🔄 Refresh token rotation for seamless session management
  • 📧 Email verification on registration with OTP
  • 🔐 OAuth2 social login (Google, GitHub)
  • 📋 Audit log — track every privileged action
  • 🌐 React admin dashboard frontend

TradeVault

Stock market platform with two deployed frontends

ReactNode.jsExpress.jsMongoDBREST APIChart.js
User App User Dashboard GitHub

Problem Statement

TradeVault is a stock market platform built with a React frontend for browsing and tracking stocks, and a separate personal dashboard where each registered user can view their own portfolio and activity. Both apps share one Express/MongoDB backend.

What I Built

  • Two React frontends: main trading app and personal user dashboard
  • Single Node.js + Express backend serving both apps via REST API
  • Stock listings with price, volume, and trend data
  • User authentication and protected routes on both frontends
  • Data visualization with charts for market trends
  • Per-user dashboard showing individual portfolio and activity
  • CORS configured for multiple frontend domains
  • Deployed all three services independently on Render

Engineering Decisions

  • Dual-frontend architecture demonstrates separation of concerns at scale
  • Shared REST API with user-specific data responses per authenticated session
  • Environment-based CORS whitelist to allow both frontends on prod
  • React state management without Redux — kept lightweight intentionally

Planned Improvements

  • 📈 Live stock price feeds via WebSocket (real-time updates)
  • 💼 Virtual portfolio — buy/sell stocks with simulated balance
  • 🔔 Price alert notifications via email
  • 📊 Candlestick chart patterns with historical data
  • 🤖 Basic ML model for stock trend prediction
